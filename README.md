# 🚀 Local Inference Performance Tester

A strict, deterministic benchmarking tool designed to evaluate local LLMs (via oMLX, vLLM, or LM Studio) on Apple Silicon. It bypasses SSD KV Caching to measure true Time-To-First-Token (TTFT), real-world generation speed (TPS), and raw memory bandwidth (Prefill TPS) across complex Python coding and extreme context-window tasks.

## ⚙️ Features
* **100% Cache-Miss Guarantee:** Injects UUIDs to force cold-read prefilling.
* **Apple Silicon Memory Profiling (Prefill TPS):** Measures how fast your M-series unified memory can ingest massive prompts (Prompt Tokens / TTFT).
* **Deep Context Stress Testing:** Includes a dynamic "Haystack" generator to push models to 15k+ token contexts to test attention degradation.
* **True Generation TPS:** Isolates TTFT from generation time for highly accurate output metrics.
* **Live Streaming:** Streams model outputs character-by-character to a secondary terminal window.
* **Script Archiving:** Saves every model's generated python code for post-mortem debugging.

## 🛠️ Setup

1. **Install the package locally:**
   ```bash
   pip3 install -e .
   ```
2. **Create the Configuration:**
   Create a `benchmark_config.json` in the root directory. Add your API endpoints, the models you have loaded in oMLX, and your test prompts. Configure Easy, Medium, Hard, and Impossible (Haystack) tasks.

## 💻 Usage (The Dual-Terminal Setup)

For the ultimate developer experience, this tool splits the process logic and the token stream into two separate windows. 

**1. Open Terminal 1 (The Observer Window)**
Navigate to the project root and open the live stream pipeline:
```bash
touch live_stream.txt && tail -f live_stream.txt
```

**2. Open Terminal 2 (The Control Window)**
Navigate to the project root and trigger the benchmark:
```bash
tester
```

Terminal 2 handles process management, context calculation, script execution, and validation. Terminal 1 streams the AI's python code character-by-character exactly as it is generated by your Mac's neural engine.

## 📊 Results Output
When the benchmark completes, a timestamped folder is created in the `results/` directory containing:
* `matrix_report.md`: A beautified Markdown table showing Pass/Fail, Generation TPS, Prefill TPS, TTFT, and Total Context Window (in kilotokens) for every model.
* `benchmark_results.csv`: Raw integer data for external data visualization.
* `scripts/`: A folder containing the exact `.py` files generated by the models during the run.
